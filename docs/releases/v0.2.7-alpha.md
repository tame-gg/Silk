# Silk v0.2.7-alpha

Silk v0.2.7-alpha moves the server to **Minecraft 26.3** and renames the server brand to **Silk**.

**Alpha baseline.** This release is built on Paper `26.3` (`d5cc7d4`), which Paper still marks as
alpha. Folia has not published a 26.3 branch, so Silk's region threading was ported forward from
Folia `ver/26.2.x` by hand, using CanvasMC's `dev/26.3` port as a reference. Test on a staging
server before upgrading a live one. The 26.2 line continues on the `dev/26.2` branch.

## Minecraft 26.3

- 26.3 rewrote most entity-targeting commands. `/kill`, `/give`, `/effect`, `/enchant`, `/clear`,
  `/xp`, `/recipe`, `/advancement`, `/attribute`, `/spawnpoint`, `/tag`, `/posteffect` and others now
  run their work on the region that owns each target and reply once every region has finished.
- Commands that touch global state, such as `/time`, run on the global region.
- The new `/compute` command is disabled until it has been checked for region safety.
- Spectators clicking a portal (new in 26.3) are teleported through the asynchronous portal path.
- End portal arrival matches 26.3's placement (players stand one block lower than other entities).
- `/mspt` keeps working through Paper's new brigadier implementation.

## Fixes

- **Plugins that cancel their tasks on shutdown (e.g. Vault) no longer throw a
  `NullPointerException`.** The legacy scheduler bridge sent internal ownerless tasks to the Folia
  scheduler, which rejects them; they now run inline.
- **`BukkitScheduler#cancelTasks(plugin)` now cancels that plugin's bridged sync tasks.**
  Previously they kept running.
- Fixed a crash when a player was created during login, caused by reading a per-region clock
  outside any region.

## Branding

The server now reports itself as **Silk** in the F3 screen, `/version` and the startup log. The
brand id (`tame-gg:silkmc`), bStats page and internal names are unchanged, so plugins that check the
brand id are unaffected.

The operator command is now **`/silk`** (`/silk status`, `/silk plugins`, `/silk report`,
`/silk reload`, `/silk bench`). `/silkmc` still works as an alias, and the `silkmc.command`
permission is unchanged.

## Plugin compatibility

The CI smoke test now runs with LuckPerms 5.5.85, EssentialsX 2.22.1-dev+24 (the first build that
supports 26.3), Vault 1.7.3, WorldEdit 7.4.6-beta-02 and ProtocolLib 5.4.0, all enabling and shutting
down without errors. WorldEdit 7.4.3 and EssentialsX 2.22.0 and older do not support 26.3.
